## Overview

A malware analysis project studying how ransomware behaves and mapping it to the MITRE ATT&CK framework. This repository describes the project at a high level. The source code is not public (see below).

## The Problem

To defend against ransomware you need to understand what it does at each stage: how it gets in, runs, spreads and encrypts. Without a common framework, those behaviours are hard to describe or compare.

## Why I Built It

Security coursework to learn how analysts break down malware behaviour and describe it in a way defenders can act on.

## Key Features

- Breakdown of ransomware behaviour by stage
- Behaviours mapped to MITRE ATT&CK tactics and techniques
- Written findings explaining how the attack works

## How It Works

1. The ransomware's behaviour was studied in an isolated environment
2. Observed actions were grouped into stages of the attack
3. Each stage was mapped to MITRE ATT&CK tactics and techniques
4. Findings were written up as a report

## What I Learned

- How ransomware operates from start to finish
- Using MITRE ATT&CK as a shared language for threats
- The importance of safe, isolated analysis environments
